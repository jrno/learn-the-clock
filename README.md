# Learn the Clock 🕐

A simple, colorful web game to help kids learn to tell time on an analog clock.

## Features

- **Multi-language support**: English, Finnish (Suomi), and Norwegian (Norsk)
- **Interactive clock**: Drag the clock hands to set the time
- **Voice feedback**: Click the button to hear the time spoken aloud
- **Simple time positions**: Only exact hours, quarter past, half past, and quarter to

## How to Use

1. Open `index.html` in any modern web browser
2. Enter your name and click "Start Playing!"
3. Drag the clock hands to set a time
4. Click "Tell me the time!" to hear it spoken

## GitHub Pages Setup

To host this game on GitHub Pages:

1. Push the code to your GitHub repository
2. Go to repository Settings → Pages
3. Under "Source", select "main" branch
4. Click Save
5. Your game will be available at: `https://[your-username].github.io/learn-the-clock/`

## Browser Compatibility

Works in all modern browsers that support the Web Speech API (Chrome, Edge, Safari, Firefox).
